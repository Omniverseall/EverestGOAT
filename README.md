# 🐐 Goat — Автоматизированный сервис жалоб и уведомлений для учителя

Веб-приложение **Goat** создано специально для учителей, чтобы в 1–2 клика формировать персонализированные замечания и автоматически отправлять их родителям учеников **совершенно бесплатно** через собственный Android-телефон учителя (или через WhatsApp в 1 клик).

---

## 🚀 Возможности системы

1. **База учеников**:
   - ФИО ученика
   - ФИО родственника (мамы, папы или опекуна)
   - Номер телефона родственника
   - Название группы / класса
   - Произвольные заметки

2. **Автоматическая группировка и фильтры**:
   - При добавлении ученика его группа автоматически превращается в кнопку-фильтр вверху экрана.
   - Мгновенное переключение между классами (например, *«Все»*, *«10-А»*, *«11-Б»*, *«Робототехника»*).

3. **Готовые виды жалоб (строго по схеме)**:
   - **Не сделал ДЗ**
   - **Опоздал на урок** (с указанием минут и быстрым выбором: +5, +10, +15, +20, +30 мин)
   - **Не пришел на урок**
   - **Не оплатил за урок**
   - **Свой вариант / Индивидуальный комментарий**

4. **Автоматический генератор текста**:
   - Автоматически подставляет в текст имя родителя, фамилию ученика, группу, количество минут и подпись учителя.
   - Живой предпросмотр сообщения с возможностью быстро отредактировать перед отправкой.

5. **Бесплатная отправка SMS через телефон учителя**:
   - Интеграция с открытым Android-приложением **Android SMS Gateway**.
   - Телефон работает как локальный SMS-шлюз по Wi-Fi.
   - SMS отправляются напрямую с SIM-карты учителя (расходуется бесплатный пакет SMS тарифа, 0 рублей сторонним сервисам).

6. **Мгновенный резервный канал (WhatsApp)**:
   - Если телефон вне сети Wi-Fi или шлюз еще не настроен, кнопка **«WhatsApp (1 клик)»** сразу открывает диалог с родителем с уже введенным текстом.

7. **Журнал истории**:
   - Хранение всех отправленных жалоб с датой, временем, получателем и статусом доставки.

## 📱 Инструкция по настройке Android SMS Gateway на телефоне учителя

Чтобы отправлять SMS полностью бесплатно и автоматически прямо со своего телефона:

1. **Скачайте приложение на Android-телефон**:
   - Скачайте официальный APK файл: [capcom6/android-sms-gateway (GitHub Releases)](https://github.com/capcom6/android-sms-gateway/releases/latest).
2. **Установите приложение и предоставьте права**:
   - При запуске разрешите приложению отправлять и просматривать SMS.
3. **Включите «Локальный сервер» (Local Server)**:
   - В настройках приложения включите пункт **Local Server**.
   - Укажите порт (по умолчанию `8080`), придумайте логин и пароль (например, `sms` и `1234`).
4. **Узнайте IP-адрес телефона**:
   - Телефон и компьютер должны быть подключены к одной Wi-Fi сети (дома или в школе).
   - В приложении на телефоне будет отображен адрес, например: `http://192.168.1.45:8080`.
5. **Внесите настройки на сайте Goat**:
   - Нажмите значок шестеренки (⚙️) в правом верхнем углу сайта Goat.
   - Введите IP телефона, порт, логин и пароль.
   - Нажмите **«Проверить связь с телефоном»**. После подтверждения связи всё готово к работе!

## 🛠️ Запуск проекта

### Требования
- Node.js 18+
- npm 9+

### Установка и запуск

```bash
# Перейдите в папку проекта
cd Goat

# Установите зависимости (если еще не установлены)
npm install

# Запуск приложения (сервер + статика)
npm start
```

Сайт будет доступен по адресу:
👉 **http://localhost:3001**

### Режим разработки (Hot Reload):

В одном терминале:
```bash
npm run server   # запуск backend API на порту 3001
```

Во втором терминале:
```bash
npm run dev      # запуск Vite dev-сервера с HMR на порту 5173
```
